PAKET WEBSITE PT. OSFA SUKSES GEMILANG
Template statis HTML/CSS/JavaScript untuk Cloudflare Pages.

ISI PAKET
- index.html: Beranda
- about.html: Tentang Kami, visi, misi, nilai
- automotive.html: Jual beli mobil/motor bekas
- commodity.html: UCO dan bahan baku plastik daur ulang
- contact.html: Kontak dan kemitraan
- 404.html: Halaman error
- styles.css: Desain responsif
- script.js: Menu mobile dan tahun footer
- assets/logo-osfa.jpg: Logo yang diberikan
- robots.txt dan sitemap.xml: dasar SEO

CARA UPLOAD KE CLOUDFLARE PAGES (UPLOAD ASSETS/DIRECT UPLOAD)
1. Unduh dan ekstrak ZIP ini terlebih dahulu.
2. Buka dashboard Cloudflare dan pilih Workers & Pages / Pages, lalu pilih project website osfa.biz.id.
3. Jika project mendukung Direct Upload, unggah isi folder hasil ekstrak (file HTML dan CSS harus berada di root upload; folder assets ikut di dalamnya).
4. Jika website saat ini tersambung ke GitHub, jangan unggah melalui Direct Upload ke project yang sama. Ganti file pada repository GitHub yang terhubung lalu commit/push agar deployment berjalan.
5. Setelah deployment selesai, cek beranda, menu mobile, setiap halaman, link WhatsApp, dan email.
6. Jika halaman lama masih tampil, periksa deployment aktif dan cache. Lakukan purge cache hanya bila memang diperlukan.
